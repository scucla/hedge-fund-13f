# Design decisions

Short records of non-obvious choices, newest at the bottom. Each one says what was decided and why.

## 2026-10-14: Python and tooling

- **Python 3.11 via `uv`**, pinned in `.python-version`. The system Python on the dev machine is 3.9; `uv` installs its own interpreter so the project doesn't depend on it.
- **The SEC User-Agent lives in `.env`** (gitignored) and is read through `SEC_USER_AGENT`. `.env.example` shows the format without the real email.

## 2026-10-14: Downloading the SEC data sets (`src/ingest/download.py`)

- **Since March 2024 the SEC publishes 13F data sets by filing-date window** (e.g. `01jun2026-31aug2026_form13f.zip`), not by calendar quarter. Before that, files were `YYYYqN_form13f.zip` and held the filings made *during* that quarter. The downloader takes *holdings* quarters and picks the file whose window contains that quarter's 45-day filing deadline, so both schemes work with one rule.
- **URLs come from the SEC listing page, not a template.** The newest file was under `/files/datastandardsinnovation/...` while older ones are under `/files/structureddata/...`; a hard-coded pattern would have broken.
- **Downloads write to a `.part` file and rename when complete**, so an interrupted download is never mistaken for a cached one.
- **Requests are spaced 0.2 s apart** (≤5/s, half the SEC's 10/s limit) and send `SEC_USER_AGENT`.

## 2026-10-14: Loading into DuckDB (`src/ingest/load.py`)

- **Values are normalized to dollars by *filing date*, not report period.** The SEC readme says market value is "rounded to the nearest dollar" starting January 3, 2023, and in thousands before. The data confirms it: a 2001 holdings report filed in 2026 is already in dollars.
- **`known_at` = filing date.** That is when the public could first see the holdings. `quarter` comes from the report period, never from the file the filing arrived in: the Jun–Aug 2026 file also contains late filings for older quarters (one goes back to 2001).
- **Three tables:**
  - `filings`: one row per 13F-HR / 13F-HR/A. Notices (13F-NT, and amendments whose report type is NOTICE) are dropped because they carry no holdings. `amendment_type` (RESTATEMENT / NEW HOLDINGS) is kept as filed.
  - `infotable_raw`: every row, keyed on the SEC's own primary key `(accession_number, infotable_sk)`. We first planned a wider key `(accession, CUSIP, put/call, discretion, other manager)`, but it isn't unique: ~222k of 3.8M rows in 2026Q2 repeat it because some filers split one position into lots.
  - `holdings`: `infotable_raw` combined per `(accession, CUSIP, put/call)`. This is the table with the strict uniqueness test. Options stay separate from the stock (`put_call` = '' for the stock itself so it can be in a key).
- **Shares and bond principal are summed into separate columns.** ~1,090 holdings report one CUSIP partly in shares (SH) and partly in principal (PRN); adding those would be meaningless.
- **$0 values are kept.** ~0.3% of rows are reported at exactly $0 (mostly tiny or worthless positions, median 8 shares). The test checks "no negative or missing values" instead of "strictly positive", plus a check that zeros stay under 1%.
- **The build writes to a temp file and swaps it in only on success**, and builds `holdings` one source file at a time. Grouping all 14M rows at once spilled several GB of temp data and failed on a nearly full disk.

## 2026-10-14: Which filings count for a fund-quarter (`src/ingest/positions.py`)

Point-in-time rule, as of a date:
1. Only filings with `known_at <= as_of`.
2. Base report = the latest 13F-HR original or RESTATEMENT amendment (a restatement replaces the whole report). 4 fund-quarters have two originals; the later one wins.
3. NEW HOLDINGS amendments filed after the base are added on top (often positions that had confidential treatment).
4. Amendments with no amendment type (9 in the current data) are ambiguous, so they're skipped with a warning. We go by `submission_type`, not `amendment_type`, to decide original vs. amendment, because 5 originals carry an amendment type by mistake.

For 2025Q3–2026Q1 both *Pershing Square Capital Management* (1336528) and *Pershing Square Holdco / Inc.* (2026053) filed holdings reports; for 2026Q2 Capital Management filed only a 13F-NT notice and Pershing Square Inc. reported the holdings. ## 2026-10-14: Seed list → filer IDs (`src/ingest/seed_ciks.py`, `data/reference/`)

- **`data/reference/` is committed; the rest of `data/` is not.** The seed list and the reviewed CIK map are small, hand-made and can't be re-downloaded.
- **Candidate CIKs come from the EDGAR quarterly full-index (`src/ingest/edgar_index.py`)**, 1999–2026: every 13F filing with the filer's name *at the time*. That finds old entity names a current-name search misses (SAC Capital → Point72, OZ Management → Sculptor, JGD Management → York, CNH Partners → AQR Arbitrage, Duquesne Capital → Duquesne Family Office).
- **The fund → CIK mapping is reviewed by hand (`seed_cik_map.csv`), not automatic.** Name matching alone is wrong too often: "York" matches New York Life, "Millennium" matches Marque Millennium, "Elliott & Associates" is now an Indianapolis wealth manager. Doubtful matches were settled by comparing business addresses in the EDGAR profile; ones that still can't be confirmed are kept with `role = uncertain` and left out of the overlap flag.
- **Only CIKs that filed at least one 13F-HR are included.** Coatue alone has ~40 fund entities that only file 13F-NT notices pointing to the manager; those carry no holdings.
- **Roles:** `primary` (the main filer today), `predecessor` (an earlier ID that stopped when another took over), `successor` (DME Capital for Greenlight), `affiliate` (another entity of the same firm filing in parallel, including founders who file personally), `uncertain`.
- **`multi_cik_same_quarter`** = two or more non-uncertain CIKs filed an original 13F-HR for the same report period (from `reportDate` in each EDGAR profile, not the filing date). It mixes two different situations that later milestones must treat differently:
  - *Hand-overs* (1–4 quarters, e.g. Elliott 2020, Brave Warrior 2012): one book changing filer, possibly reported twice in the switch quarter.
  - *Parallel filers* (e.g. Soros, Two Sigma, AQR, Millennium, Point72, Steadfast, Icahn): either separate books (Point72's regional entities) or the same book reported twice (a founder filing personally). Which one needs a holdings comparison; that's for the feature milestone, so no fund-quarter gets double-counted.
- **`style_guess` is a weak label**, copied as given. It will be checked against hand labels in Milestone 4.

## 2026-10-14: CUSIP → ticker (`src/securities/cusip_map.py`)

- **The SEC 13(f) list has no tickers.** It gives issuer name, a short description and an options-listed flag; tickers come from OpenFIGI.
- **CUSIPs that start with a letter are CINS codes** (non-US domicile: G = Cayman/Bermuda/Ireland, H = Switzerland, N = Netherlands, L = Luxembourg…). OpenFIGI only maps them as `ID_CINS`. Retrying them that way took unmapped value from 4.7% to 0.13% (Chubb, ASML, Seagate, Spotify, Linde, Accenture, Medtronic…). Last resort: the FIGI some filers put in their own 13F rows.
- **Listing choice:** the US composite listing (`exchCode = US`), then any US exchange, then anything.
- **Security class from OpenFIGI's `securityType` before `securityType2`**: ETFs come back as `ETP` / `Mutual Fund`, and reading the second field first labelled every ETF a mutual fund.
- **Coverage is measured by value, not rows:** 99.8–99.9% of seed-fund value maps to a ticker in every quarter. The unmapped rest is mostly SPACs and recently delisted names.
- **The mapping is current, not point-in-time.** OpenFIGI returns today's ticker for a CUSIP. A company that changed ticker maps to its new one (fine for prices, since Yahoo history follows the security), and a CUSIP whose security no longer trades may not map at all. `security_master.known_at` is NULL to make that explicit.

## 2026-10-14: Prices (`src/securities/prices.py`)

- **yfinance adjusted closes (`auto_adjust=True`)**, so returns include dividends and splits. Adjusted history is restated by Yahoo after every dividend; that changes price *levels* but not returns, and only returns are used.
- **Survivorship bias.** Yahoo drops most delisted tickers. Stocks that were acquired or delisted between the holdings date and today have no prices, so their features and labels are missing, and missing labels skew toward names that left the market (often takeovers, which tend to have positive returns, or failures, negative). This is a known limitation of the free stack; CRSP fixes it. Price coverage by value is reported every run, and `prices_missing` lists every symbol with no data.
- **Only US listings in the priced classes** (common, ADR, ETF, closed-end fund) are downloaded. Warrants, rights, units and preferreds (0.2% of value) are out of scope; their OpenFIGI symbols rarely match Yahoo's.
- **Rate limits:** Yahoo throttles bulk downloads. Only successful symbols and genuine "no data" answers are cached; everything else is retried with exponential backoff. A symbol counts as "no data" only when yfinance's error message says so ("possibly delisted", "no price data found"); yfinance 1.7 keeps no public per-symbol error record, so the messages are read from its log. Two earlier versions got this wrong (one cached throttled chunks as empty, one read an error dict yfinance no longer fills) and made AAPL and SPY look delisted. Final run: 9,219 of 9,370 symbols priced, 97.0–98.8% of seed-fund value per quarter; the 151 confirmed misses are mostly names acquired or delisted since (CyberArk, Comerica, Verona Pharma, Frontier, TEGNA, Civitas).

## 2026-10-14: Fundamentals (`src/securities/fundamentals.py`)

- **SEC companyfacts per issuer, every version kept, `known_at` = filing date.** A restatement is a new row with a later `known_at`, never an overwrite. Features as of date d use, for each concept and period, the latest version filed on or before d.
- **USD only.** Foreign filers reporting in other currencies get no fundamentals rather than mixing currencies.
- **Fallback concepts in priority order** (e.g. `StockholdersEquity`, then including non-controlling interest; IFRS equivalents). For shares outstanding: the cover-page `dei:EntityCommonStockSharesOutstanding`, then balance-sheet shares, then weighted-average basic shares. Companies with several share classes (Alphabet) tag the cover-page count per class, which companyfacts leaves out, hence the fallbacks.
- **Sector from the SIC code in each issuer's EDGAR profile.** That is the company's current SIC, not a history; SIC codes rarely change.

## 2026-10-14: Factors (`src/securities/factors.py`)

- **Fama-French 5 factors + momentum, daily and monthly, from Ken French's library**, converted from percent to decimals. French revises past values when he updates the files, so this is a fixed-after-the-fact series. It's used for beta and later risk adjustment, not as a feature anyone could have known at the time.
- **FF12 industries come from French's own `Siccodes12` file**, not a hand-typed table. SIC codes outside every listed range are industry 12 ("Other"), as French defines it.

## 2026-10-14: `stock_quarter` (`src/securities/stock_quarter.py`)

- **As of the calendar quarter end** (owner decision): 13F holdings are reported as of that date, so it's the natural snapshot. The label `ret_next_q` is the next calendar quarter's total return, with its own `label_known_at`. Lining up the 45-day filing lag is for the prediction and backtest milestones.
- **Book-to-market is NULL when book equity is negative, zero or missing; the stock stays in the table** (owner decision). Dropping them would remove exactly the distressed and buyback-heavy firms some funds specialise in.
- **Gross profitability (Novy-Marx 2013) instead of Fama-French operating profitability** (owner decision): FF's definition needs interest expense and SG&A, which XBRL filers often don't tag, so coverage would be poor. Annual gross profit / total assets at the same fiscal year end; revenue − cost of revenue when gross profit isn't tagged.
- **No market cap (so no size or book-to-market) for ADRs.** Their XBRL share count is in ordinary shares, not ADRs (one TSMC ADR = 5 shares), and the ratio isn't tagged. ADRs still get book equity, profitability, asset growth and the price-based features. ETFs and closed-end funds get price-based features only.
- **Staleness guards:** a "quarter-end price" must be from the last 10 days; book equity older than ~18 months and share counts older than ~13 months are ignored.
- **Beta and volatility** use daily returns over the past 365 calendar days (at least 120 days), regressed on the FF market excess return. Daily data gives a usable estimate within one year, which a 60-month monthly beta can't for recent listings.
- **Momentum (12-1)** is the return from the month-end 12 months before the quarter end to the month-end 1 month before it, skipping the last month (short-term reversal).
- **Fixes found by checking the real table:**
  - *Linked CIKs (`data/reference/issuer_cik_links.csv`, hand-reviewed).* ExxonMobil reorganized under a new holding company in 2026 (CIK 2115436, first XBRL filing 2026-08-03), and the SEC ticker file now points XOM there. The history is under the old Exxon Mobil Corp CIK (34088), so linked CIKs' facts are loaded under the current issuer. Other issuers whose filings start after they were first held are almost all 2025 IPOs and spin-offs (Figma, Chime, Circle, Klarna, Ralliant, Amrize); having no fundamentals before their first filing is correct point-in-time behaviour, not a gap.
  - *Share counts ≤ 0 are ignored* (36 rows had market cap 0 from a mis-tagged zero).
  - *A fact's period end must also be on or before the quarter end*, not just its filing date: one filing carried a balance sheet dated after its own filing date.
- **Known gaps, not fixed:** banks and insurers have no gross profit, so `gp_at` is NULL for them (expected); Canadian issuers filing on Form 40-F (Teck, Rogers, Manulife, CGI) have little or no XBRL data; Yahoo has no prices for names delisted since (survivorship, above).
- **Finding, not a bug:** defensive and energy stocks (KO, PEP, PG, JNJ, WMT, XOM, CVX) have small *negative* betas in 2026Q2 (12 months to June 2026), after positive betas in earlier quarters. The pipeline was checked: SPY, priced and aligned the same way, has 0.992 correlation and 0.96 beta with the FF market factor. It is a market regime, and worth remembering when beta is used as a feature.

## 2026-10-15: Pre-commit checks on `stock_quarter` (owner-requested)

- **Negative book equity: no tag problem.** Of common-stock rows that have a book-equity value, 10–12% are negative per quarter (8.6–11.1% of all common-stock rows). The 25 largest by market cap are the known buyback- and debt-funded names (AbbVie, Philip Morris, Dell, McDonald's, Booking, Lowe's, Altria, Starbucks, Marriott, McKesson, HCA, Hilton, TransDigm, AutoZone, O'Reilly, Yum, Verisk…), all from the primary `StockholdersEquity` tag. Five were checked against the balance sheet in the 10-Q itself (EDGAR's rendered R pages, cached under `data/raw/edgar/spotcheck/`), and all match to the reported precision: ABBV −6,656, LOW −9,270, SBUX −8,465.1, MCD −1,286, VRSK −1,167.7 ($M). Verisk confirms the parent-only line is used, not total equity including non-controlling interest.
  - **Why the rate is above market-wide levels:** the universe is what hedge funds hold. SPACs (SIC 6770) are 181 of 527 negatives in 2026Q2; 83% of SPACs show negative stockholders' equity because their redeemable Class A shares sit in temporary equity, outside stockholders' equity. Without SPACs the rate is ~8%, the rest being cash-burning small caps (biotech, recent IPOs with accumulated deficits) and de-SPACs whose SIC code is no longer 6770. `bm` is already NULL for all of them; anyone filtering out SPACs can use `sic = 6770`, though that misses de-SPACs.
- **Negative betas are real; no alignment bug.** For the year to 2026-06-30, betas against SPY daily returns are within 0.03 of the Fama-French ones for every name checked (KO −0.28, PEP −0.17, PG −0.06, JNJ −0.10, WMT −0.04, XOM −0.38, CVX −0.34; AAPL 0.87; SPY on itself 1.00). Against SPY *weekly* returns (52 points, noisier): CVX −0.43, JNJ −0.39, XOM −0.84 stay negative; KO −0.01 and WMT 0.00 are flat; PEP +0.19 and PG +0.41 turn slightly positive. Kept as computed (daily, FF market). Defensive and energy stocks had roughly zero-to-negative market sensitivity that year.
- **Beta after French's data ends: fall back to SPY** (my call). For days after the last date in the FF daily file, the market excess return is SPY's daily return minus the last published RF. `beta_market` = `'ff'` or `'ff+spy'` and `n_proxy_days` count the SPY days, so the switch is visible. Chosen over marking betas incomplete because SPY tracks the FF market closely (daily correlation 0.992, SPY beta 0.96 on it), and dropping September would also have dropped those days from `vol`. No row uses the fallback yet (the latest quarter ends 2026-06-30); 2026Q3 holdings will.

## 2026-10-15: Milestone 3 Phase A — fund books (`src/features/books.py`)

- **One `fund_id` per seed fund per quarter.** For every fund-quarter with more than one filing CIK, the portfolios are compared: overlap = Σ min(w_a, w_b) over common positions. **≥ 0.9 → the same book reported twice: keep one** (primary > successor > affiliate > predecessor, then the larger book). **Otherwise the books are separate and added up.** Every decision is in `fund_book_decisions` with its reason and overlap.
- **Decisions on the current four quarters:** no pair is a duplicate; the highest overlap is 0.57 (Two Sigma Investments vs Two Sigma Advisers). So all parallel filers are added: AQR + AQR Arbitrage (overlap 1%), Millennium + WorldQuant Millennium (18%), Soros Fund Management + George Soros personally (7–9%), Pershing Square Capital Management + Pershing Square Holdco/Inc. (9–11%), Point72 + its regional entities (5–27%), Two Sigma Investments + Advisers. Icahn, Trian and Steadfast didn't co-file in these quarters. The duplicate rule is there for the hand-over quarters the backfill will bring.
- **Two Sigma Securities is excluded** (`data/reference/fund_book_exclusions.csv`): it's a broker-dealer, and its 13F is market-making inventory, not an investment decision.
- **Empty books are kept as facts.** A 13F-HR whose only row is a placeholder (CUSIP 000000000, "N/A", no value or shares) means the fund held no 13F securities that quarter. Mantle Ridge did this in 2026Q2 after selling Dollar Tree. Placeholder rows are dropped from positions; the fund-quarter is kept in `empty_books` and in `fund_quarter` with `n_positions = 0`. Rows with CUSIP 000000000 but a real issuer and value (filer errors, $85M in total) are kept as positions without stock features.

## 2026-10-15: Positions (`src/features/positions.py`)

- **Two weights.** `weight` = value / total reported value, all rows, so it sums to 1 per fund-quarter as specified. `weight_long` = value / total of non-option rows. 13F reports options at the *underlying's* value, so they would swamp the book (Citadel: 80% of reported value is options); concentration, active share and tilts use `weight_long`.
- **Splits are detected from the data, not a corporate-actions feed.** For each stock and quarter, each fund that held it in both quarters gives (reported shares t / t−1) ÷ (value-implied shares t / t−1, using Yahoo's split-adjusted close). Funds that just held on show the split ratio exactly; the median across funds is snapped to a standard ratio (1.25, 1.5, 2…50, 100 or reciprocals) **only if within 1.2%**. Real splits land within 0.5% (NFLX 10.000, NOW 5.000, BKNG 25.06, KLAC 10.01, TPL 3.006, BN 1.502). Spin-offs and special dividends also move Yahoo's adjusted prices without changing share counts, and land further off (BDX 1.28 after its 2026 spin-off, LILAK 1.47, AIV 1.40, ELME 6.5); applying them would invent 20%+ position cuts, so they're rejected. 59 splits accepted, 37 candidates rejected (`stock_splits`). Missing a spin-off is harmless, because share changes compare reported counts directly.
- **Position age is left-censored** in the first quarter of data (`age_censored`); the backfill fixes that for later quarters.
- **Crowding** = number of *other* seed funds holding the same security long that quarter (by ticker; GOOG and GOOGL count separately).
- **`known_at` = the fund-quarter's filing date** (latest among its included CIKs). Holdings-based features can't be known before the filing, which is after the quarter end; stock characteristics stay as of the quarter end. The tests check each against its own date.

## 2026-10-15: Fund-quarter features (`src/features/fund_quarter.py`)

- **Active share uses a proxy benchmark.** There are no free S&P 500 constituent weights, so the benchmark is the 500 largest *issuers* by market cap in `stock_quarter`, cap-weighted. Issuer level, so Alphabet's two share classes aren't counted twice. Limits: `stock_quarter` only covers stocks some seed fund holds (in practice every large cap), and ADRs have no market cap, so they can't be in the benchmark.
- **Turnover = min(buys, sells) / average long book value** (the mutual-fund definition). Buys and sells are split-adjusted quantity changes at this quarter's price; a new position is a buy of its value, an exit a sale of last quarter's value grown by the stock's return. NULL when the previous quarter isn't filed. Known property: a fund that only sells (e.g. Mantle Ridge selling Air Products) shows 0, because the measure ignores one-sided flows. Values above 1 (possible through price moves) are clipped and flagged (`turnover_clipped`); none so far.
- **Factor tilts:** each characteristic (log ME, log B/M, 12-1 momentum, GP/A, asset growth, beta) is winsorized at 1%/99% and z-scored across that quarter's common stocks (equal-weighted), then averaged with `weight_long` over the fund's stocks that have a value; `cov_*` is that covered weight. The cross-section is *stocks held by seed funds*, not the whole market, so a z-score of 0 means "average hedge-fund holding". Every fund tilts large because funds value-weight large caps against an equal-weighted cross-section.
- **A DuckDB trap:** `greatest(NULL, 0)` returns 0, not NULL. Clipping turnover that way turned "no previous quarter" into "no trading"; a synthetic test caught it.
- **`gross_turnover` = (buys + sells) / 2 / average long book** (owner request), next to the standard min(buys, sells) measure. The min ignores one-sided trading; gross doesn't: Mantle Ridge selling Air Products in 2026Q1 is 0 vs 0.31, and its full exit in 2026Q2 (an empty book) is 0 vs 1.0. For an empty book after a filed quarter, turnover = 0 and gross_turnover = 1 by definition. Median across fund-quarters: 0.19 standard, 0.25 gross.
- **Flows are bounded by what's possible.** Bond rows (principal, no shares) use value changes, not quantity × price: filers aren't consistent about principal units, and one Sculptor convertible (JD.com) implied a $123B trade on a $3–19M position, pushing gross turnover above 1. And no sale can exceed last quarter's holding grown by the stock's return. Since that fix, no fund-quarter needs clipping.

## 2026-10-15: Fixes found during the Phase B EDA (security master)

- **Delisted US stocks were mapped to foreign cross-listings.** After a takeover or going-private, OpenFIGI no longer returns the US listing, so the mapper fell back to e.g. "EA*" (Mexico), "HO1" (Germany) or "WBD*", which have no Yahoo prices or SEC CIK. About $230B of position-value over the four quarters was affected (Electronic Arts, Warner Bros Discovery, Hologic, Exact Sciences, Kellanova, Dayforce, Avidity…). Fix: CUSIPs whose best listing is non-US are re-queried with OpenFIGI's `includeUnlistedEquities`, which returns the old US listing (`map_source = openfigi_unlisted`); if there is still none, the ticker is the one most listings share (HON, not HONGBP; `openfigi_foreign_listing`). Value on non-US listings is now $21.6B.
- **Delisted issuers also drop out of the SEC ticker file,** so they had no CIK and no fundamentals. Fallback: match the issuer name against every company that reported total assets in the SEC XBRL frames API for 2024–2025 (us-gaap and IFRS), which still includes companies acquired since. Names are normalized (suffixes like INC, CORP, LTD, CL A, /ISRAEL dropped) and only one-to-one matches are accepted (`issuer_cik_source = xbrl_name_match`, 280 CUSIPs). Common/ADR value without a CIK fell from 2.2% to 0.35%. Spot-checked: EA 712515, Hologic 859737, Kellanova 55067, Carnival 815097, Air Lease 1487712, CyberArk 1598110.
- **Known leftover:** Carnival's CUSIP maps to the London code "0EV1L" (no US listing returned, and the most common ticker is a venue code), so it has fundamentals but no prices.
- **The price cache is keyed by end date**, so a run on a new day re-downloads everything (it did once, successfully). To fix before the Phase C backfill.

## 2026-10-15: EDA notebook (`notebooks/eda_milestone3.py`, paired `.ipynb`)

- Written as a jupytext percent script, paired with the executed `.ipynb`, so diffs are readable and the outputs are kept. Figures go to `docs/figures/`. Colors are the dataviz reference palette, validated with its `validate_palette.js` (all gates pass for the seven series hues; the three light hues under 3:1 contrast get direct labels); diverging blue–gray–red for z-scores; never a dual axis.

## 2026-10-16: Milestone 4 — fingerprint definitions (`src/features/fingerprint.py`)

- **Point-in-time is checked per row**, not assumed: a stock's characteristics are used only if `stock_quarter.known_at` (quarter end) and `fundamentals_known_at` are on or before the fund-quarter's filing date; otherwise the stock counts as missing (lower `cov_*`). `max_input_known_at` stores the latest date of any input used and a test requires it ≤ `known_at`. With the current tables no characteristic is excluded (they are all as of the quarter end, before any 13F filing), so the filter is a guard, not a change.
- **Holding period** = value-weighted average of how many consecutive quarters each current position has been held, **capped at 12 quarters**, plus `long_held_share` (weight held ≥ 12 quarters). Without the cap, ages can reach 13 quarters in 2018 but 46 in 2026, because the data start in 2015Q1: in a time split the test years would look like longer holders for no reason but the calendar. With the cap the feature has the same meaning in every quarter from 2017Q4 on.
- **Tilts:** size, value, momentum, profitability only (the four asked for); investment and beta stay in `fund_quarter`.
- **Known approximation:** FF12 sectors come from each issuer's current SIC code (`issuer_profile`), not the SIC at the time. Industry reclassifications are rare, so this is a small look-ahead; noted rather than fixed.

## 2026-10-16: Milestone 4 close — returns-based factor regressions and style drift

### Returns-based FF5 + momentum regressions (`src/models/factor_regressions.py`, `docs/factor_regressions.md`)

- **No fund returns exist, so the return series is the 13F clone:** quarter q's long book (non-option `weight_long`) bought at the quarter-end close and held untouched through the three months of q+1, weights drifting with prices. Monthly excess returns are regressed on Mkt-RF, SMB, HML, RMW, CMA, Mom (French monthly) with Newey-West t-stats (3 lags), 2018Q2 on. **Why the clone is the right comparison:** the holdings tilts describe the same long book, so the two methods measure one portfolio two ways (characteristics vs return co-movement). It is *not* the fund's return: no shorts, leverage, options, fees or intra-quarter trading.
- **Quarter-end start, not the filing date:** the question is "what exposures did this book have", so the book is held from when the fund actually held it. A copycat strategy would start at the filing date (~45 days later); that is a Milestone 6 backtest question, not this one.
- **Not point-in-time, deliberately:** a full-period regression uses every month of returns, so the loadings are a description of the fund and are **never** a model feature. `style_classifier.py` does not read them.
- **Unpriced stocks:** a stock with a missing monthly return leaves the book from that month on and the rest is renormalised; months with under 60% of the starting book still priced are dropped (1,941 of 8,958 fund-months), funds need 36+ months. **12 seed funds drop out**, nearly all merger-arb/event-driven (Glazer, Water Island, Westchester, Pentwater, HBK, Davidson Kempner, Magnetar, Sculptor) and private-biotech books (Baker Bros, Perceptive, Deerfield): their targets are acquired and Yahoo drops them. This is the same delisting gap as the `ret_next_q` open item, and it hits the clone of exactly the funds whose returns come from deals closing.
- **Results (65 seed funds, Spearman across funds, holdings tilt vs loading):** size vs SMB **−0.67**, value vs HML **+0.52**: the two methods agree on rank. Momentum vs Mom only **+0.14** (+0.29 with market + Mom alone): the quarter-end momentum tilt is a snapshot, and books turn over within the quarter, while Mom is rebalanced monthly. Profitability vs RMW **−0.34**, the wrong sign, and it is not collinearity (−0.36 with market + RMW alone). The holdings measure is gross profits / assets (Novy-Marx); RMW sorts on operating profitability over book equity, after SG&A and R&D. Growth/tech books have the highest gross-profitability tilt (median +0.49) and the most negative RMW loading (−0.35): high gross margins, heavy operating spend. **Lesson to quote:** a characteristic tilt and a factor loading only agree when they define the characteristic the same way.
- **Sign agreement is not the test.** Almost every fund loads positively on SMB (same-sign share 0.09) even though its size z-score is positive, because the z-scores are relative to the stocks seed funds hold and the loadings are relative to the cap-weighted market. Ranks are comparable; levels are not.
- Sanity: by style, multi-managers and quants have R² ~0.97 and market beta ~1.0 (diversified books); healthcare has beta ~0.55, SMB +0.75, RMW −0.68 (small unprofitable biotech). Largest single clone month: Magnetar +131% in May 2025, real (CoreWeave was 47% of its 2025Q1 long book and went from $40 to ~$150).

### Style drift (`src/models/style_drift.py`, `docs/style_drift.md`, figures 10 and 11)

- **Out-of-fund predictions for every quarter.** `style_predictions` is in-sample for seed funds' 2018–2022 quarters, where a model just repeats the fund's label, so drift would be invisible. Drift reuses the classifier's final variant (v2 + 13D) and its 5 fund folds: each fold's model, trained on the other funds' 2018–2022 rows, scores all quarters 2018+ of its held-out funds. Holdout funds are scored by the model trained on all seed funds. Scoring a fund's 2019 rows with a model that saw other funds' 2022 rows is acceptable here: this describes history, it doesn't forecast, and no fund's own label or rows enter its predictions.
- **"Changed" =** argmax of the mean class probability over the first 8 quarters differs from the last 8, **and both winning means are ≥ 0.6**. Without the confidence condition 33 of 93 funds change, mostly between two styles the model was never sure of. **0.6 was chosen after looking at the counts** (0.5: 23, 0.6: 11, 0.7: 4, all in the report); it is a reading threshold for a chart, not a tuned model parameter, and nothing downstream uses it.
- **Check for a training-cutoff artefact:** the model is trained on 2018–2022, so changes piling up at 2023 would be suspicious. The share of funds whose top prediction changes quarter to quarter is 18% at 2023Q1, the same as 2020Q2, 2023Q2 and 2024Q4 (typical 10–15%). No clear break.
- **11 funds changed**, several matching the holdings: ValueAct value_concentrated → growth_tech (top holdings Citi, KKR, Morgan Stanley in 2019; Amazon, Salesforce, Disney, Roblox, Meta in 2025); York event_driven → value_concentrated (the wind-down left one name, NEXT, at 81–92% of the book); Appaloosa → growth_tech (mega-cap tech plus BABA); Suvretta growth_tech → healthcare from 2023 (consistent with its v2 relabel to healthcare, though the review dated the biotech tilt from 2020). Others are model boundaries rather than fund changes: Renaissance multi_manager → quant (2018–19 only) and Millennium multi_manager → quant (2023+), the multi-manager/quant confusion the classifier already shows. Median stability (share of quarters equal to the fund's most common prediction) is 0.82.

## 2026-10-16: Delisting gap — 13F-implied returns, delisting returns, merger-target label

Closes the `ret_next_q` open item before Milestone 5. Reports: `docs/delisting_returns.md`, `docs/merger_targets.md`, `docs/factor_regressions.md`.

**Finding that shaped the plan:** no missing label comes from a price series that *ends*. Every one is a stock with no Yahoo price at all (~70k common/ADR stock-quarters, ~5,400 CUSIPs). In 89% of them a seed fund still holds the stock next quarter, so a delisting return alone would fill ~11%. Owner decisions: fill ordinary quarters with 13F-implied returns; median price across funds, flag > 5% disagreement; spread quarterly returns evenly over three months in the clone; Shumway −30% for performance delistings.

**13F-implied returns** (`src/securities/implied_prices.py`): median value/shares across seed funds (holdout funds never move a seed number). Price-only, no dividends. Splits from 13F share ratios, kept only if they make the price change smaller (a fund doubling its position shows the same share ratio but no price halving). ~2% of implied prices (9% in 2022Q4, the first quarter filed in dollars) are off by 1000× on small names that have too few filers for the ≥3-filer fix in `universe.py`; a quarter-on-quarter ratio > 100× is rescaled. Moves beyond 3× seen by fewer than 3 funds are flagged `big_move_few_funds`, not dropped: against Yahoo ~80% are real, and dropping them would bias the label against extreme returns. Against Yahoo: median abs error 0.17 pp, correlation 0.97 on unflagged rows.

**Why each delisting happened** (`src/securities/sec_events.py`, `delistings.py`, `deal_docs.py`): one pass over the EDGAR full-index 2014–2026 gives each held issuer's Form 25/15, merger proxies, tender offers and 425/S-4 (the index lists a filing under every company on it, so the target's CIK shows the deal and the counterparty). An exit (held by a seed fund at q, by none at q+1) is a delisting if a Form 25/15 falls in q+1. Of 6,278 exits of unpriced stocks: 1,261 cash and 595 stock acquisitions, 317 performance, 580 other (387 SPACs), and 3,525 not delisted in q+1 (1,698 sold by every seed fund, 604 CUSIP changes, 1,223 with no CIK). Choices worth defending:
- Anchor on the delisting, use only target-side evidence: the index doesn't say who is the bidder (Celgene's own 2015 and 2018 tender offers appear under its CIK).
- `performance` = bankruptcy 8-K (1.03), or last price < $1, or a listing notice (3.01) with price < $5. A 3.01 on a pricier stock was usually a deal without a proxy (UK schemes: Shire, WNS; short-form mergers); with a completion 8-K (2.01/5.01) it is an acquisition, otherwise `other`.
- Deal terms come from the "entitled to receive … for each share" sentence in the first 800 KB of the proxy / 14D9 / 425 (sec.gov ignores Range requests, so the download is streamed and cut). **Sanity band** against q's 13F price: 0.9–1.5× if the deal was already announced at q (the target trades near the deal value; this rejects missed stock legs like Time Warner's cash-only parse at 0.57×), 0.5–4× if announced inside q+1 (real premia: DallasNews $15 vs $4.30, Volta $0.86 vs $0.36).
- Stock legs: acquirer's nominal price on the delisting date = its median 13F price at q × its adjusted-close return since (Yahoo closes are adjusted, the exchange ratio is nominal). Without a nominal price, a pre-announced stock deal gets the acquirer's own return from q's end (the target tracks ratio × acquirer), bounded to 0.5–2×.
- Fallback with no usable terms: 0% from the last 13F price (657 deals). CVRs, elections and proration are not modelled (VMware's cash-or-stock election is approximated by the acquirer return).
- Known deals: Twitter +23.6%, Seagen +7.9%, Activision +1.5%, Celgene +7.6% (cash + 1 BMY, CVR ignored).

**Filled label** (`src/securities/labels.py`): `ret_next_q` = Yahoo, else delisting return, else 13F-implied; every other row says why in `ret_source` (`missing:sold_out`, `missing:no_cik`, …). `ret_next_q_yahoo` keeps the old label. Share of seed long value with a label: **2015 66% → 99%**, 2018 79% → 99.2%, 99.3% or more from 2019 (0.2–0.7% still missing). `label_known_at` is when the filled return became public (last 13F filing behind the price, or the delisting), never before q's end.

**Selection bias (owner's point):** a 13F-implied return needs a holder at q+1. On Yahoo-priced stocks, rows still held at q+1 return +4.0% (median +1.5%, 7% below −30%); rows every seed fund sold return −3.5% (median −7.0%, 20% below −30%). So `missing:sold_out` rows are likely losers, and a model trained only on labelled rows sees slightly optimistic outcomes for stocks funds abandon. The value at stake is small (0.2–1% of value per year still missing), but **any model must report results with and without unlabelled rows, and must not use "has a label" as a feature.**

**Task C exits never depend on a price** (`src/features/position_moves.py`): exit = held at q, filed at q+1, not held at q+1; a fund that stopped filing has no label. `forced_exit` (acquisition or performance delisting in q+1; 16,642 of 402,498 exits) comes from SEC filings. A test builds the table with no price tables in the database at all. Add/trim use Yahoo splits, else 13F-only splits.

**Factor regressions:** with the filled returns spread over three months, all 12 dropped seed funds pass coverage (77 seed funds regressed, was 65), plus two merger-arb holdout funds. Merger-arb betas are near zero (Glazer 0.01, Water Island 0.14, Westchester 0.21); partly real (deal-pinned prices), partly the even spread, which smooths those stocks. Cross-fund agreement barely moves (size vs SMB −0.67 → −0.53, value vs HML 0.52 → 0.52). Yahoo-only loadings kept in `fund_factor_loadings_yahoo_only`.

**Merger-target weak label** (`src/features/merger_targets.py`): announced target = from the first target-side deal filing to the delisting, from the completed-acquisition list (1,827 deals). `target_share` separates event-driven funds with AUC 0.99. At the 10% threshold (fixed beforehand): 5 funds flagged, all event-driven, recall 5/12. It finds the pure merger-arb books (Water Island, Pentwater, Westchester, Glazer, Magnetar; holdouts Alpine and TIG) and misses multi-strategy event-driven funds (Davidson Kempner, Canyon, Taconic, Sculptor), whose deal positions are partly in confidential-treatment amendments (above). **Weak label and validation measure only, never a classifier feature:** the list knows which deals later completed. Missed: broken and still-pending deals, and targets no seed fund held.

**Known limitations:** the 0% fallback for 657 deals without parsed terms; 1,223 exits with no CIK are unclassified; SPAC exits get no return; implied returns are price-only.

## 2026-10-16: Milestone 5 — main embedding method chosen on pre-2023 quarters (logged before any 2023+ metric)

- **Rule, fixed before running** (`src/models/clustering.py` docstring): HDBSCAN per quarter on seed funds; average each method's stability ARI (q vs q-1, noise as singletons), ARI vs the v2 style labels (noise as singletons) and econ gap (within- minus across-cluster correlation of next-12-month 13F-clone returns, market-demeaned); rank methods on each, lowest rank sum wins, ties to lower noise share.
- **Selection window:** 2016Q1–2022Q4 (28 quarters); the econ gap only to 2021Q4 so its return window ends by 2022Q4. No 2023+ clustering metric had been computed when the choice was made.
- **Result (quarterly means):**

| method | noise | purity | purity (shuffled labels) | label ARI | stability ARI | econ gap | rank sum |
|---|---|---|---|---|---|---|---|
| fund2vec | 0.26 | 0.73 | 0.33 | 0.40 | 0.74 | 0.43 | 5 |
| cosine | 0.46 | 0.73 | 0.33 | 0.30 | 0.78 | 0.50 | 5 |
| svd | 0.16 | 0.71 | 0.35 | 0.34 | 0.57 | 0.43 | 8 |
| nmf | 0.09 | 0.68 | 0.37 | 0.28 | 0.53 | 0.40 | 12 |

- **Choice: fund2vec**, on the tie-break: it ties with the cosine baseline and calls far fewer funds noise (0.26 vs 0.46). Cosine's high stability is partly an artefact of noise: a fund that is noise in both quarters agrees with itself. Stored in `data/reference/embedding_choice.json`; the full run reads it and never rewrites it.
- **A first `select` run was discarded:** a NaN in the first quarter (no previous quarter for stability) made the polars means NaN, so the ranking ignored stability and the econ gap. Fixed (NaN → null) and re-run on the same pre-2023 quarters. That run had computed nothing after 2022.

## 2026-10-16: Milestone 5 — embeddings, clusters, crowding (design choices)

Reports: `docs/embeddings_clustering.md`, `docs/crowding.md`, reading in `docs/fund_map.md`. Code: `src/features/embeddings.py`, `src/models/clustering.py`, `src/models/crowding.py`.

- **sqrt(weight) rows.** Each long book (issuer level, share classes merged) enters as sqrt of its weights: rows have unit norm, cosine = Bhattacharyya overlap, and one 40% position can't dominate the similarity.
- **Fit on seed only, project the rest.** Every per-quarter model (SVD 16, NMF 12, fund2vec 32 dims) is fitted on seed books filed by quarter end + 60 days (99% of seed books are filed by day 48). Holdout funds and background filers are transformed into it. Each row's `known_at` = the later of the fund's own filing and the latest input to the fit.
- **Alignment anchored on stocks, not funds.** SVD loadings and fund2vec word vectors of issuers present in both quarters are matched by orthogonal Procrustes, chained forward from 2015Q1 (q uses only q-1's frame). Anchoring on funds would let the rotation absorb real fund drift. NMF themes are matched by a Hungarian permutation so they stay non-negative and readable. Effect: median quarter-to-quarter SVD move falls from 0.45 to 0.09.
- **Centring.** SVD and fund2vec fund vectors are centred on the seed mean before normalising (otherwise the "average fund" direction makes every pair similar). NMF theme mixes are not centred.
- **fund2vec corpus.** Per quarter, the last 4 quarters of seed books filed by asof(q); 10 sentences of 40 tokens per book, drawn with probability = weight; vocabulary = issuers in ≥ 2 seed funds; `workers=1` for reproducibility.
- **HDBSCAN** with min_cluster_size 3, min_samples 2, chosen a priori for 77 funds and not tuned. Noise is reported per method (fund2vec 26–28%, cosine 46–51%, SVD 15%, NMF 9%) and counted as singletons in every ARI, so labelling everything noise can't look stable. k-means (k = 8) is reported as a comparison and is worse on stability for every method.
- **Background filers:** the 500 largest long books per quarter for 2025Q3–2026Q2 with active share ≥ 0.7 (the seed 10th percentile is ~0.71) and ≥ $100M, from the bulk 13F data already on disk (no download). Display-only. See the follow-up entry for the ETF-share cap added after the first run.
- **Crowding uses conviction holders (≥ 1% of the book).** Without the floor, the 17-fund multi-manager/quant cluster "crowds" ~1,700 names held at 0.05%. Crowded = ≥ 3 funds and ≥ 50% of one cluster. Returns are size-quintile adjusted, plus a regression on crowded, log(1 + holders), log size, beta and momentum, so crowding isn't confused with popularity or growth exposure. Delisted names earn the delisting return, then cash.
- **Episodes:** COVID = 2019Q4 books (filed before the crash), 2020Q1 returns; growth unwind = 2021Q3 books, returns 2021Q4–2022Q2. Both books fall inside the selection window.
- **Results in one line:** fund2vec clusters held up after 2023 (purity 0.74 vs 0.35 shuffled, stability 0.76). Crowded names did fine in COVID (+11% vs controls, t = 1.5) and badly in the growth unwind (−23%, t = −2.6). Within-cluster overlap was not unusually high going into either episode.

## 2026-10-16: Milestone 5 follow-up — ETF-share cap on background filers, crowding-floor sensitivity

- **ETF cap (owner's request).** Background filers now also need ≤ 25% of their long 13F value in ETFs, closed-end and mutual funds (`security_master.security_type2 = 'Mutual Fund'`, which covers 99.7% of 2026Q2 13F value). Why 25% and not 0: seed funds hold ETFs too, mostly as hedges (2025Q3+: median 3%, 90th percentile 21%, 95th 27%), so a zero cap would screen out books that look like seed funds. The cap binds: the median ≥ $100M filer is 35% ETFs and funds.
- **Effect.** The filers nearest the multi-manager/quant cluster fall from 386 to 338, and their largest are now diversified long-only active managers (Dodge & Cox, Boston Partners, State Farm) instead of wealth platforms (LPL, Envestnet). The specialist neighbourhoods grow: healthcare 15 → 27, Tiger growth 18 → 33, merger arb 3 → 6. **Seed and holdout embeddings and every cluster assignment are identical** (checked against a snapshot); the background is projected, never fitted.
- **Crowding floor kept at 1%; sensitivity at 0.5% and 2%** (`crowding_sensitivity`, `docs/fund_map.md`). The sign holds at every floor: crowded names beat size peers in COVID and lagged them in the growth unwind. Significance is highest at the pre-chosen 1% (growth unwind t = −2.6, vs −1.9 at 0.5% and −1.3 at 2% with only 7 names). The 1% floor was not chosen because it gave the best t; it was set before this table existed.

## 2026-10-16: Milestone 6 — Task C (next-quarter moves and new buys)

Reports: `docs/task_c_baselines.md` (committed before any model), `docs/task_c_results.md`, `docs/task_c_leakage_audit.md`. Code: `src/features/task_c.py`, `src/models/task_c_common.py`, `task_c1.py`, `task_c2.py`, `task_c_baselines.py`, `leakage_audit.py`, `task_c_report.py`.

**Prediction date = the fund's own quarter-q 13F-HR filing date** (point-in-time view, so a 13F-HR/A filed later never feeds a feature; 312 panel fund-quarters have one). Every feature group carries its own `known_at`; the audit checks each row.

**Point-in-time peers and clusters (owner's fixes 1 and 2).**
- Other funds file quarter q on different dates, often after this fund. Peer features use each other seed fund's *latest filing public by the prediction date* (quarter ≤ q, and not older than q-1), not "quarter q". A naive quarter-q count would have used a not-yet-public filing on 360k of 1.31M rows (27%). `positions.crowding` is that naive count, so it is banned as a C1 feature (the audit checks); `n_peer_hold` replaces it.
- A quarter's Milestone 5 clustering is fitted on filings up to ~60 days after quarter end, so it is used only if its `known_at` ≤ the prediction date; otherwise the previous quarter's. 79% of rows end up on q-1 clusters. Cluster ids are not features (HDBSCAN labels aren't aligned across quarters); in-cluster peer counts are. Holdout funds were never clustered: their cluster features are null.

**Embargo (owner's fix 3).** A training row's label is public at the fund's q+1 filing, so 2021Q4 labels arrive inside 2022. Fit rows whose `label_known_at` is after the first prediction date of the scored period are dropped: 39,803 train rows against 2022 (cutoff 2022-05-04), and the same at the 2022/2023 boundary (cutoff 2023-05-09) for the train + val refit that scores the test years.

**Tuning covers one regime.** Every choice (C, LightGBM leaves / min child / rounds, C2 grids) was made on 2022 alone: a rate-hike, growth-unwind year with high turnover (hold share 21% vs 18% in test). A choice that suits 2022 may not suit a calmer year; walk-forward re-tuning per year would be the fix, and the test years (2023-2026Q1) are the out-of-regime check. The LightGBM grid was nearly flat on 2022 (val log-loss 1.148-1.153 across all 12 settings), which limits the damage.

**Scope choices.**
- **Stock universe only** (a `stock_quarter` row: common, ADR, ETF, fund). Warrants, SPAC units, debt, preferreds and unmapped CUSIPs (~9.5% of long rows) have no characteristics and aren't the stock decisions Task C is about. ETFs stay: hedges are decisions too.
- **Forced exits dropped** (acquisitions, performance delistings): not the fund's choice. Nearly all 0%-deal-fallback returns (`delist_last_13f_price`) are forced exits, so only 2 C1 rows carry one; the `ret_clean` filter mostly removes `missing:*` stocks (no CIK, SPACs, sold-out names). Results move by ≤ 0.002 in log-loss with or without them.
- **Train on seed funds only**; holdout funds are a separate, never-trained-on test.
- **Multi-manager and quant funds kept** and reported separately: they are 83% of test rows, so pooled numbers are mostly about them.
- **Not done** (plan's optional items): GRU, two-tower, regression target, tuning the 10% band.
- **Hand style labels are not features**: they were assigned in 2026 with hindsight. Style is used for reporting only.

**Baselines.** Hold is the *smallest* class (18-21%), not 50-60% as the plan guessed, so "predict hold" scores macro-F1 0.08. The useful baselines are the fund's own action rates (expanding history: macro-F1 0.373; last quarter: 0.380 on test). Activist, value and healthcare funds hold 50-60% of positions; multi-managers 8%.

**C1 results (test 2023Q1-2026Q1, seed).** LightGBM with everything (`lgbm_full`, chosen by 2022 log-loss) reaches macro-F1 0.487, log-loss 1.124, exit AUC 0.80, against 0.380 / 1.267 / 0.69 for the best baseline; logistic regression sits between (0.458 / 1.173). **Peer and cluster lift is real but tiny:** −0.0035 log-loss (95% bootstrap over fund-quarters −0.0054 to −0.0018), no macro-F1 change, and nothing outside multi-manager/quant funds. Herding as measured here adds little once a position's own size, age and last move and the fund's own habits are known. SHAP: position size (`log_value`), last share change, position age and the fund's hold/exit rates dominate; `n_peer_hold` and `cl_frac_hold` are the top peer features (10th and 13th). On holdout funds the model still beats the baselines (macro-F1 0.43 vs 0.32), but the full variant is worse than base (0.415 vs 0.429): with no clusters their cluster features are null, which the model learned from noise funds.

**Calibration:** trim, hold and add are well calibrated; exit is overconfident above 0.6, almost entirely one fund (Ancora Advisors, an activist with a wealth-management book of many small positions it often keeps; 1,606 rows at p_exit > 0.8). Left as found: fixing it would mean tuning on test.

**C2 results (test, seed, 893 fund-quarters).** Popularity NDCG@20 0.066, cluster popularity 0.094, item-item CF 0.148, ALS 0.156, **re-entry 0.164**. Re-entry (buy back what you exited in the last four quarters, then popularity) is the best method on 2022 and on test, and every recommender works much better with four quarters of history than one. That says most predictable new buys are *returns* to old names, and CF/ALS mostly rediscover them. Cluster popularity beats overall popularity by ~40%, the clearest sign in Task C that the Milestone 5 clusters carry trading information. Each CF method's settings were chosen on 2022 (item-CF: sqrt weights, 4 quarters; ALS: 64 factors, reg 0.1, alpha 10, 4 quarters); neither beats the re-entry baseline, and that is the honest result.

## 2026-10-20: Milestone 7 — Task D backtest

Report: `docs/backtest.md` (conclusion hand-written in `docs/backtest_conclusion.md` and included); figure 21. Code: `src/backtest/engine.py`, `strategies.py`, `signals.py`, `run.py`. Owner decisions: the defaults below, a 2021+ subperiod for every clone (coverage), the timing caveat for unpriced names, alphas only through 2026-08.

- **One rebalance per quarter, the day after the 45-day deadline.** Each portfolio uses only filings with `known_at` on or before the deadline (rolled to the next trading day) and trades at the next close, so "enter at the next trading day's close after known_at" holds for every filing used. Late filers wait a quarter. The alternative, trading each fund's filing on its own date, would split one portfolio into ~70 trade dates for little gain; consensus and cluster portfolios need everyone's filing anyway.
- **Daily returns from Yahoo where they exist; otherwise the filled quarterly return spread over the quarter.** 21–34% of seed long weight had no daily price in 2018–2023 (34% in 2018, 21% in 2023; about 10% by 2026). Those names earn the 13F-implied or delisting return spread evenly over the quarter's trading days, as in the Milestone 4 clone. The filled returns run quarter end to quarter end, while positions are held filing date to filing date, so their timing is approximate, and spreading smooths them (lower vol and betas). That's why every clone is also reported 2021+. Names with no return earn 0%; at −30% for "every seed fund sold it" names, annual returns move by 0.0–0.9 pp.
- **Delisted before the trade = not bought.** A 13F can list a stock that was taken over between quarter end and the trade (CSRA, MuleSoft in the 2018Q1 books). The Form 25/15 date is public that day, so selection skips such names for the next-ranked one. After a delisting inside the window the position is cash, which is a known outcome, so it counts as covered rather than missing. This fix lowered the event-driven clone's "no return" share from 39% to 16–17%.
- **Model signals scored on everything a trader would see.** Milestone 6's saved test predictions covered only labelled, non-forced rows. Whether a fund files next quarter, and whether a stock is acquired, are future information. So C1 now also writes `c1_all` (every stock-universe position), and `lgbm_full` is refitted with the frozen 2022 choices (booster saved) and scores all of it. C2 lists are produced for every seed fund-quarter, not only those that later bought something. `c1_panel` is unchanged (1,309,286 rows; the leakage audit still passes).
- **Selection rules fixed before running:** 20 names, equal weight, common and ADR (ETFs are hedges, not ideas). Consensus: most seed funds' top-10 stock positions; funds with more than 500 positions in that filing don't vote (point in time, unlike the hand style labels). Clusters: latest clustering public by the deadline, named by majority hand style (the name only, not the membership), same-name clusters merged. C1: Σ p(add) over holders, the expected number of adders. C2: number of funds with the name in their top-20 list.
- **Benchmarks:** SPY (adjusted close) and an equal-weight portfolio of every common/ADR issuer seed funds hold, on the same calendar and costs. Alphas are monthly, compounding the same trading days for strategy, factors and benchmarks, with Newey-West t-stats (3 lags). Self-regressions are left blank.
- **Two style clusters are mostly cash** (discretionary 32 of 35 quarters, value 23 of 35: no cluster with that majority style existed). They are shown separately, not in the main tables.
- **Result:** no strategy earned a significant FF5 + momentum alpha. Consensus 9.3% vs SPY 14.5% (2018+); growth clone ≈ SPY with beta 1.18; frozen C2-ALS 24.1% vs SPY 21.9% over the 2023+ test years (alpha t = 0.9); C1 adds 16.5%. The re-entry list, the best C2 predictor, was the worst portfolio. Costs of 10 vs 20 bp change little (at most 0.8 pp a year).

## 2026-10-21: Quarterly forward test (`src/live`)

One command per quarter, `uv run python -m src.live.quarter <q>`: extend the pipeline to quarter q, grade the q-1 forecast against the q filings, issue the q forecast from the frozen models, then commit, tag `forecast-<q>` and push (owner's call: automatic). Files: `predictions/<q>_c1.csv.gz`, `<q>_c2.csv.gz` (owner's call: separate gzipped files), `<q>.json`, and the append-only `predictions/scorecard.csv`. App page: "Live track record".

- **Frozen means byte-for-byte.** The C1 booster from Milestone 7 (the trainval refit with the 2022-chosen settings) is committed gzipped in `models/frozen/`, with its SHA-256, features, ALS settings and the train+val class shares in `manifest.json`. Every run checks the hash before scoring. A test fails if `src/live` contains any fitting or selection code. ALS is refitted at each prediction date with fixed settings and seed, as in the backtest: that's the frozen procedure, not retuning.
- **Baselines are pre-registered.** Each C1 forecast row also stores the fund's historical and last-quarter action shares as of its filing date. Grading compares the model against those saved columns, not against anything recomputed later.
- **Proof of timing.** The issue date is the day the forecast's manifest was first committed. A fund whose next filing is dated on or before that day is not graded (13F filers can file from the day the quarter ends). Every file's SHA-256 is in the manifest and the commit message; the grader refuses a file whose hash changed, and refuses a forecast that was never committed. Git dates are self-reported, so the push to GitHub, timestamped on GitHub's side, is the stronger evidence (owner's call: no OpenTimestamps).
- **Ingest with `backfill`, never `load`.** The raw data-set zips were deleted after loading, so `load` (which rebuilds `13f.duckdb` from whatever zips exist) would wipe the four windows it holds. `backfill` appends one data set's seed and holdout rows to the history databases and is resumable.
- **Timing.** Q3 filings are due 2026-11-16; the SEC's Sep–Nov data set appears some weeks after the window ends (about mid-December). The run must happen between then and 2026-12-31, before early Q4 filings start; it warns otherwise. A faster EDGAR-direct ingest (`check_units.py` already fetches filings) is a possible later improvement.
- **Rebuild only the C1/C2 path,** with `LAST_QUARTER` now an environment override in `db.py`. Stale caches are expired first: XBRL companyfacts and the French factor files cached before the quarter ended, and the SEC ticker file. No report or figure under `docs/` is regenerated: `clustering.build_tables` was split out of `clustering.main` so the live run writes tables only.
- **Embeddings and clusters are append-only:** recomputed in full, then earlier quarters restored from a snapshot, so a past forecast's inputs can never move. The rehearsal found 0 of 24,424 earlier assignments differed anyway.
- **Rehearsals, before the first live forecast:**
  1. **2026Q1 predict and grade** into a scratch folder. All 40,944 predictions equal the backtest's frozen scores exactly. The graded macro-F1 (0.485) and log-loss (1.131) equal the same metrics computed from the Milestone 6 panel to 6 decimals.
  2. **Offline rebuild of 2026Q2** on a copy of the database (every local step, about 6.5 minutes). Labels, positions, new buys and clusters are identical. Features differ only by floating-point summation order (at most 1.4e-14), and the resulting forecast is identical (max |Δp| = 0, same C2 lists).
  - Not exercised: the download steps. They are the same functions the milestones used, but the first real test is the 2026Q3 run.
- **Disk:** about 7 GB free on the dev machine; a quarterly data set is 1–2 GB before backfill deletes it, and `backfill` stops below its free-space floor.
- **First forecast: 2026Q2** (from the August filings; Milestone 6's test ended with 2026Q1). Some seed funds may already have filed Q3 early in October; they won't be graded, and the count is reported.
